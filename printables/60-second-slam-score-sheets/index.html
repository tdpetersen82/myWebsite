How 60 Second Slam scoring works

Everyone gets the same category and the same sixty seconds to write one answer for every letter, A to Z. The scoring twist is what makes it a game: only unique answers count. Compare letter by letter — if two players both wrote "apples" under A, both get nothing; the player who wrote "avocado" scores the point.

That rule quietly changes how you play. The obvious answer is usually the shared answer, so the winning instinct is the second thing that comes to mind, not the first.

Using these sheets

Each page carries two rounds — write the round's category on the line at the top of each column, answer down the alphabet, and use the tick column while comparing to mark which letters scored. The score line at the bottom takes the round total; a standard game is five rounds, so one sheet per player covers a game with a spare column for the tiebreak.

Table rules worth agreeing

Decide up front whether proper nouns are fair game, whether an answer must start with the letter exactly (no "an apple" under A), and who rules on disputes — the reader of the category card is the usual referee. Skipped letters simply score nothing; nobody is obliged to fill all 26.

Frequently asked

How long is a game? Five rounds, highest total wins.

Do shared answers score? No — any answer written by more than one player cancels for everyone who wrote it.

Do you need the boxed game? These sheets replace the pad, not the game — you still need the category cards and timer, or a phone timer and your own categories.
